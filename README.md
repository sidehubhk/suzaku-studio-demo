# SUZAKU Studio Demo

A modern Astro rebuild of the [SUZAKU Games](https://www.suzakugamestudio.com/) studio presence — cyberpunk neon, East Asian ghost-story atmosphere, and motion-led presentation.

## Stack

- **Astro** — static pages + islands
- **React** + **Framer Motion** — hero parallax, glitch, scroll reveals
- **Lenis** — smooth scrolling
- **Tailwind CSS v4** — theme tokens (phoenix crimson, void black, electric cyan)

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Astro prints (usually `http://localhost:4321`).

## Build

```bash
npm run build
npm run preview
```
